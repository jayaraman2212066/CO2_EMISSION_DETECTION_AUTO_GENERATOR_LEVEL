## ✨ Features
- 🤖 **ML Predictions**: TensorFlow/Keras model for CO₂ level forecasting
- 📊 **Real-time Analysis**: Instant CO₂ categorization (Normal/Moderate/High)
- 🎤 **Voice Feedback**: Speech synthesis for accessibility
- 📱 **Responsive UI**: Modern glassmorphism design
- 🔄 **Auto-Generation**: Random CO₂ data for testing
- 💾 **History Tracking**: SQLite database storage
- 🌐 **Multi-Platform**: Railway, Render, Docker support

- **Frontend**: HTML5, CSS3, JavaScript
- **Database**: SQLite (production-ready)
- **Deployment**: Render (Free Tier Optimized)
